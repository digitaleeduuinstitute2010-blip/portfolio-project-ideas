# Portfolio Project Ideas for Freshers

No clients yet? Build proof of skill with these weekend projects.
Maintained by [99Eedu Institute, Kolkata](https://99eedu.com).

## Digital marketing
**Mock campaign plan for a local business**
- Pick a business type (café, tuition centre, salon)
- Write: goal, audience, offer, 3 ad texts, weekly content calendar
- Optional: set up a test store and run a tracking audit

## Graphic design
**Brand kit for a fictional brand**
- Logo + colour palette
- 3 social media posts
- 1 flyer
- Short note explaining each decision

## UI/UX design
**Redesign one screen of a real app**
- Describe the problem users face
- Sketch, wireframe, then prototype in Figma
- Explain why your version is better

## Web development / WordPress
**4-page small business website**
- Home, About, Services, Contact
- Mobile-friendly layout, working contact form
- Basic speed and SEO settings

## Present every project the same way
1. **Problem**
2. **Process**
3. **Solution**
4. **Result**

Add screenshots. Keep it to one page. Label practice work honestly as practice.
